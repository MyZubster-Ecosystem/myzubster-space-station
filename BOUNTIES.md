# Bounties — MyZubster Space Station

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Space Station bounties may cover mission models/APIs, simulator work, telemetry ingestion/validation, dashboards, audit trails, Gateway integration, tests and documentation.

## Evidence

Software/simulator work must be reproducible from a clean checkout. Physical robot evidence, when applicable, must be explicitly distinguished from simulation.

## Scope truth

This is a software MVP/space-robotics simulation track; bounty completion does not imply completion of physical or orbital space infrastructure.

## Reward truth

MYZ in the core platform is an internal reward/accounting ledger. Historical 250 MYZ definitions are work/reward records, not external settlement proof. External XMR/token payment requires independent verification.

## Issues

Use this repository's GitHub issues and link implementation evidence/PRs to the bounty issue.
